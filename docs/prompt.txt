### 1. **Error de `add_class` no definido**:
- El filtro `add_class` no está funcionando en `home.html` y arroja un error.
- Solución:
  - Crear un filtro personalizado en Django para agregar clases CSS a los formularios (ver ejemplo abajo).

**Paso 1: Crear filtro personalizado en `busyschedule/templatetags/custom_filters.py`:**

```python
from django import template

register = template.Library()

@register.filter(name='add_class')
def add_class(value, arg):
    """Agrega una clase CSS a un elemento HTML"""
    return value.as_widget(attrs={'class': arg})
````

**Paso 2: En `home.html`, cargar y usar el filtro:**
